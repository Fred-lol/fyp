# AquaLoad Role / Function Map

## Customer
- Register and Login
- Manage Profile / Password / Theme
- Browse available seafood stock
- Place, update and cancel eligible orders
- View own orders
- Track status
- View latest assigned-lorry location through REST API when available

## All Authorized Staff
Warehouse Administrator, Loading Supervisor and Seafood Supplier share the same operational functions:
- Staff Dashboard
- Seafood Management
- Customer Order Management
- Order Status Management
- Lorry GPS Tracking view
- Lorry Profile Management
- Standard Box Template / Inventory Management
- Space Optimization
- 3D Loading Visualization / Loading Sequence
- Loading Reports & Analytics
- User Account Management
- Profile / Password / Theme

## Customer checkout addition

Customers can access the Order Review & Payment page from Order Seafood. The payment page is not part of Staff navigation because it is a Customer checkout function. All Staff can view the recorded payment status/amount inside Customer Order Management, consistent with the shared Staff-access rule.
